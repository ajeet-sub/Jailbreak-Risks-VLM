# Jailbreak-Risks-VLM

In this branch, I have uploaded the main fine-tuning evaluation component. To access the results, look in the Results_JBv and the MM-SafetyBench Directories. Keep in mind that for the Jailbreakv results, the responses produced degenerate outputs, so the script shared_valid.py does a heuristic filter to remove them from the evaluation sample.
